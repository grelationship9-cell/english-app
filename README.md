# 旅行英語の練習アプリ

海外旅行で英語に困らないための、自分用の学習アプリ。

## コンセプト

毎晩15分、旅行の1場面を「聞き取れないところから」体験して、自力で切り抜けられるようにする。

1ターンの流れ:

```
聞く → 何て言ってた？(3択) → Sorry? と聞き返す
  → ゆっくり再生 → 答え合わせ → 自分も言ってみる
```

正解しても必ず聞き返しを通す。「分からなければ聞き返せばいい」を
特別な行為ではなく当たり前の動作として身につけるため。

## ファイル

| ファイル | 中身 |
|---------|------|
| `index.html` | アプリ本体 |
| `app.js` | セッションの進行 |
| `style.css` | 見た目 |
| `data/*.json` | 場面データ（セリフ・訳・選択肢） |
| `voice.html` | 読み上げ機能の動作確認・訛りの聞き比べ |
| `mic.html` | 音声認識で「通じるか」を判定する検証 |

場面を足すときは `data/` に JSON を追加するだけ。プログラムは触らない。

## 使うもの

素の HTML / CSS / JavaScript のみ。ビルド不要。

- 読み上げ: 端末内蔵の Web Speech API（無料・通信不要）
- 音声認識: SpeechRecognition（https が必須）
- 学習記録: 端末内に保存（localStorage）。サーバーには何も送らない

## 動かす

```bash
python -m http.server 8000
```

<http://localhost:8000/> を開く。
